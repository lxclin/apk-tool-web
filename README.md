# APK Tool Web

安卓 ADB 适配工具 Web 端 —— 零安装，浏览器即可操作。

## 快速开始

1. 下载 [APK Tool Proxy.dmg](download/APK-Tool-Proxy.dmg)
2. 安装并启动代理应用
3. 打开本页面，自动连接本地 ADB
4. USB 连接安卓手机，开始使用

## 功能

- 推送 Config 到设备
- 执行 zygote_build 注入脚本
- Logcat 实时日志监听（按 UID / 广告平台过滤）
- 应用缓存清除、强制停止
- APK 本地安装、URL 跳转、APKPure 搜索

## 系统要求

- macOS (Apple Silicon / Intel)
- Chrome 浏览器
- 安卓手机 USB 连接
- **不需要安装 Python、ADB 或任何依赖**
